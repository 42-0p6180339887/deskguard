# 离席守护 · DeskGuard

用于在你离开自己的电脑后，按输入活动触发拍照并保存在本机。适用于 Windows 10 / 11 的 64 位系统；便携运行，通常无需安装或管理员权限。

## 开始使用

1. 将整个程序文件夹解压到可写位置，双击 `DeskGuard.exe`。启动后处于“未布防”，摄像头不会自动开启。
2. 点击“测试拍照”，再点击“查看最近照片”确认镜头和画面。默认摄像头编号为 `0`；选错镜头或无法打开时，可依次尝试 `1` 到 `10`。
3. 点击“开始布防”。摄像头准备完成后，默认留出 **15 秒**离开时间；倒计时结束才响应输入，并自动收起到系统托盘。
4. 返回后按 **Ctrl + Alt + F9** 停止，再查看照片。

布防期间，程序保持相机会话，收到触发后请求拍照并保存。相机初始化成功并不代表画面已验证，请先使用“测试拍照”检查取景。程序不播放快门声，也不为每张照片弹窗；摄像头指示灯由系统和硬件控制。

## 操作与设置

| 操作或设置 | 作用 |
| --- | --- |
| Ctrl + Alt + F9 | 开始布防 / 停止 |
| Ctrl + Alt + F10 | 显示 / 隐藏主窗口 |
| 系统托盘图标菜单 | 布防或停止、显示窗口、退出 |
| 窗口右上角 × | 完全退出，并关闭摄像头与输入检测 |
| 最短拍照间隔 | 默认 3 秒；连续操作会合并，避免大量连拍 |
| 照片容量上限 | 默认 2 GiB；界面标为 GB，按 1024³ 字节计算 |
| 布防期间保持电脑唤醒 | 默认开启，允许屏幕熄灭 |

主窗口不会置顶。托盘图标可能收在任务栏的“隐藏图标”区域。若快捷键已被其他软件占用，运行日志会提示，请使用窗口按钮或托盘菜单。

保安鹅图标保持静态，图案中的红点只是装饰。查看实际状态时，将鼠标停在托盘图标上阅读文字提示，或打开主窗口；不要仅凭图标判断是否正在布防或拍照。

“桌宠模式”提供两种外观。选择“静默保护”后不显示桌宠，保护功能保持不变；选择“鹅鹅巡逻”后，只有开始布防时鹅才会出现，并沿主屏幕边缘缓慢移动。它不会抢焦点或拦截鼠标点击，停止布防或锁屏时会自动隐藏。也可在托盘菜单切换模式。宠物图案中的摄像头红点是装饰。

照片默认存入程序所在文件夹的 `Photos/YYYY-MM-DD/`，也可在“照片位置”中更换目录。`Photos/events.jsonl` 仅记录保存时间、文件名和触发原因；设置保存在程序旁的 `settings.json`。程序不保存按键内容、不录音、不联网上传。达到照片上限或磁盘空间不足时会停止，保留已有照片；整理照片或更换目录后可重新布防。

## 与 Codex 同时运行

默认模式忽略 Windows 标记为“模拟注入”的鼠标、键盘事件，以减少 Codex 图形界面操作引起的误拍。这是尽力过滤，不能保证区分所有真人操作、自动化工具和设备驱动输入。Windows 的判定依据见 [键盘注入标记](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-kbdllhookstruct)与[鼠标注入标记](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-msllhookstruct)。

“兼容模式”改为检查当前会话的输入活动，可能改善部分触屏设备的检测，同时也会把模拟输入算作活动。触屏点击、滑动、多指手势都需在本机测试，不能保证每一种手势都能触发。[微软活动检测说明](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getlastinputinfo)

Codex 在 Windows 上操作桌面应用时，需要保持设备解锁，目标应用可见；锁定状态下无法继续这类操作。纯命令和文件任务本身通常不会生成模拟鼠标、键盘事件，具体任务仍需实测。[OpenAI 电脑操作说明](https://learn.chatgpt.com/use-cases/use-your-computer-with-codex)

本工具只负责记录，不拦截他人输入、不自动锁屏、不验证使用者身份，也无法保护一个未锁定的桌面。

## 锁屏、睡眠与故障

检测到锁屏或 UAC 安全桌面后，程序会尽快暂停并释放摄像头；返回普通桌面后重新连接并倒计时。桌面检测采用轮询，切换和已经发出的拍照请求可能存在短暂延迟，因此不能把该行为当作安全边界，也不提供锁屏或登录界面的拍摄保证。Windows 对安全桌面的访问有单独限制。[微软桌面隔离说明](https://learn.microsoft.com/en-us/windows/win32/winstation/desktops)

“保持电脑唤醒”只在运行期间提出防止自动睡眠的请求，停止后释放，不修改系统电源设置。手动睡眠、合盖或管理策略仍可能使电脑休眠；睡眠期间无法检测和拍照。该选项也不阻止自动锁屏。[微软唤醒请求说明](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-setthreadexecutionstate)

无法打开摄像头时，检查编号、Windows 相机权限，以及是否被会议或相机软件占用。出现“需要检查 · 已停止”时，先查看窗口中的原因，处理后重新测试拍照和布防。

## 首次使用前：本机验收

制作过程中未开启你的摄像头或实际监测输入，以下硬件效果尚未验证。请按顺序完成：

1. **摄像头：**测试拍照，确认照片清晰、镜头正确、目录可写。
2. **鼠标：**布防并等待倒计时结束，移动或点击鼠标；停止后确认新增照片。
3. **键盘：**重新布防，等待结束后按一个普通按键；停止后确认新增照片。
4. **触屏：**分别测试点击、滑动和常用手势。默认模式漏检时，停止后切换兼容模式重测；记录兼容模式可能产生的误拍。
5. **Codex：**默认模式下布防，让 Codex 执行实际需要的命令任务与图形界面任务，你暂不操作；停止后检查是否误拍，再决定使用哪个模式。
6. **停止与恢复：**分别通过快捷键、托盘菜单停止，确认之后的输入不再新增照片；测试退出、锁屏后恢复，并确认返回桌面会重新倒计时。

每次测试查看照片前先停止，避免查看照片时的操作再次触发拍照。
