- 使用便携运行环境实测窗口 ICO 解码、托盘自定义图标加载及退出释放，通过。

## v0.1.0 已完成的验证

- 离线测试：活动合并与拍照间隔、输入标记过滤、照片保存、磁盘容量、异常清理、配置容错、摄像头组件通信、托盘恢复、发布包隐私隔离和构建失败处理，通过。
- 自带 Python 运行环境：隐藏界面初始化和模拟 JPEG 保存通过。
- 最终 `DeskGuard.exe` 入口：自检退出码 0，自带运行环境、隐藏界面和模拟照片保存通过。
- 系统托盘：图标创建、两组快捷键注册、退出释放通过。测试后已关闭。
- 子进程退出：未发送开启指令的辅助进程可随 Windows Job Object 关闭而退出，通过。
